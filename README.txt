MATCHDAY TOURNAMENT MANAGER — FRONTEND JAVASCRIPT DEMO

Run locally:
1. Extract this folder.
2. Open the folder in VS Code.
3. Install the "Live Server" extension.
4. Right-click register.html > Open with Live Server.
5. Register a student with one game.
6. Login as demo admin:
   Email: admin@matchday.demo
   Password: admin123
7. Approve/reject applications from Admin Dashboard.
8. Login as the student to see the status.

Important:
- This version uses HTML, CSS, JavaScript and browser localStorage only.
- Data stays in the same browser profile on the same device. It does not sync between devices/users.
- Passwords are stored in localStorage in this demonstration. Do not use real passwords or real student data.
- The admin demo credentials are public in this package. This is NOT secure authentication.
- GitHub Pages can host this demo, but a real multi-user system requires a secure backend/database.
- Existing tournament pages are retained. Student registration, login, dashboard and admin approvals are working as a local frontend demonstration.
